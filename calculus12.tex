\section{Set Theory}
The elements of a set can be chosen abstractly. For instance, in a university, a set of people can contain students, teachers, and faculty. We denote the objects of the set as generalized things. For instance, numbers, animals, and personal emotions are all things that we can place in a set.

Denote the set by the curly-brackets $\{\}$. The following operations all

\begin{definition}
    \begin{itemize}
        \item Let $\cup$ define set union. Ie, if $x \in A, y \in B, \{x,y\} \in A\cup B$.
        \item Let $\cap$ define set intersection. This is defined as if $x, y \in A\cap B$, then $x \in A, x\in B, y\in A, y\in B$.
        \item Let $A$ be a set. Let $B$ be a subset of $A$, that is, $B\subset A$.  Then, let $B^c$ denote the compliment of $B$, or the points in $A$ that are not in $B$. If $A = B$, then $B^c = \emptyset$.
    \end{itemize}
\end{definition}

We can use these operations to discuss some interesting groups of numbers. The following are a few useful sets.

\begin{definition}
    The following are commonly used sets;
    \begin{itemize}
        \item Natural numbers: $\mathbb{N} = \{1,2,3,\dots \}$ 
        \item Whole Numbers: $\mathbb{W} = \{0, 1,2,3,\dots \}$
        \item Integers:$\mathbb{Z} = \{\dots, -3, -2, -1, 0, 1,2,3,\dots \}$
        \item Rational Numbers: $\mathbb{Q} = \left\{\frac{x}{y} : \{x,y\} \in \mathbb{Z}, y\neq 0\right\}$
        \item Irrational Numbers: $\mathbb{P} = \left\{x : x\text{ cannot be written as a fraction.}\right\}$
        \item Real Numbers: $\mathbb{R} = \mathbb{Q}\cup \mathbb{P}=\mathbb{Q} \cup \mathbb{Q}^c$
    \end{itemize}
\end{definition}

\subsection{Properties of Set Operations}
The operations of set union and intersection allow us to learn about the properties of sets under union, intersection, and compliment. We can define a few interesting theorems or results that allow us to start getting some logic in the world. 

\begin{theorem}
    \begin{equation}
        X^c \cap Y^c = (X \cup Y)^c
    \end{equation}
    \begin{proof}
        To prove this, we need to show that the LHS is equal to the RHS. Consider $X \cup Y$. If $x\in X^c$ then $x \notin X$. If $y\in Y^c$, $y\notin Y$. The overlap of the compliment sets, $X^c \cap Y^c$, contains neither $x$ nor $y$. Thus, $x, y \in X\cup Y$, This completes the proof as since $x,y \notin X^c \cap Y^c$, then we must have that $(X\cup Y)^c = X^c \cap Y^c$.
    \end{proof}
\end{theorem}

For a union or intersection of many sets, define the notation;
\[
\bigcup_{i=1}^\infty X_i = X_1 \cup X_2 \cup \dots, \quad \bigcap_{i=1}^\infty X_i = X_1 \cap X_2 \cap \dots
\]

\begin{theorem}
    \begin{equation}
            \left(\bigcap_{i=1}^\infty X_i\right)^c =     \bigcup_{i=1}^\infty X_i^c 
    \end{equation}
    \begin{proof}
        Let $x_i \in X_i$, $x_i\notin X_i^c$. Split this into two cases, where $\cap X_i \neq \emptyset$ and $\cap X_i = \emptyset$. 
        \begin{itemize}
            \item $\cap X_i = \emptyset$, then for every $x_i$ there exists a disjoint set $X_j$ which doesn't contain $x_i$. This implies that $x_i \in X^c_j$.
            \item $\cap X_i \neq \emptyset$. If the intersection is not empty, then there exists $x_i \in X_1, X_2, \dots$. Thus, since $x_i$ is simultaneously contained within every intersected set;  $x_i \notin \cup X_i^c$.
        \end{itemize}
        This completes the proof stating that the compliment of the intersection of all sets will contain all points outside of the intersection which is the union of each individual compliment. 
    \end{proof}
\end{theorem}

\subsection{Functions}

We can furthermore define functions as sets by adressing rules. Depending on these rules, a function can map an element in set $A$ to set $B$. This is defined using the following notation;
\begin{equation}
    f : A \rightarrow B
\end{equation}

\begin{example}
    Suppose $f(x) = 3x^2$ for $x\in \mathbb{R}$. Define the set $\mathbb{R}_+ = [0, \infty)$. Thus, we would say that;
    \begin{equation}
        f: \mathbb{R} \rightarrow \mathbb{R}_+
    \end{equation}
\end{example}

We can classify functions based on the uniqueness of their mappings. For a function $f: A \rightarrow B$, we assume that each element in $A$ maps to at most one element in $B$. A general function takes an element in $A$ and maps to at most one value in $B$. Not all elements need to be mapped to, and some points can be visited multiple times. \textbf{Injectivity} implies that each input on $A$ produces a unique result in $B$. Ie, there are no duplicates. However, not all elements in $B$ are nessecarily covered. \textbf{Surjectivity} implies that all outputs in $B$ are mapped to, however, multiple $x\in A$ may map to elements in $B$. A map is \textbf{bijective} if every point in $A$ uniquely maps to a point in $B$. This is also known as a set which is injective and surjective. See Fig. \ref{fig:bijective} for a visualization.

There are some useful notation. Here, for $f:X \rightarrow Y$, define the \textbf{image} as the set $Y = f(X)$. similarily, define the inverse image, or \textbf{preimage} as the set $X = f^{-1}(Y)$.

\begin{definition}
    general functions have the following properties when used in tandem with set union and intersection. In addition, we present the inverse operations. 

    \begin{enumerate}[label=\alph*.]
        \item $f(A\cup B) = f(A) \cup f(B)$
        \item $f(A\cap B) \subseteq f(A) \cap f(B)$
        \item $f^{-1}(A\cup B) = f^{-1}(A) \cup f^{-1}(B)$
        \item $f^{-1}(A\cap B) = f^{-1}(A) \cap f^{-1}(B)$
        \item $f^{-1}(f(A)) \supseteq A$
        \item $f(f^{-1}(C)) \subseteq C$
    \end{enumerate}
\end{definition}
\begin{proof}
    We aim to prove each statement mentioned above. Let $f:X \rightarrow Y$ and $A, B\subset X$, $C\subset Y$. 
    \begin{enumerate}[label=\alph*.]
        \item  Let $x\in f(A\cup B)$. Thus, there exists a $y$ such that $y \in A\cup B \rightarrow x \in f(y)$ Since $y\in A, \rightarrow x \in f(A)$ or $y\in B \rightarrow x \in f(B)$. Thus, $f(A\cup B) \subseteq f(A) \cup f(B)$. Similarily, in the converse, suppose that $x\in f(A)$. then, there will exists a $y\in A$. Since $y \in A, y\in (A\cup B)$. Thus, $f(A) \subseteq f(A\cup B)$. Or more relevantly, $f(A) \cup f(B) \subseteq f(A\cup B)$. The converse with $B$ is trivial. Thus,  $f(A\cup B) = f(A) \cup f(B)$.
        \item Let $x\in f(A \cap B)$. There exists a $y$ such that $y\in A$ and $y\in B$, so $y \in A\cap B$. So, if $y\in A$, $x\in f(A)$ and $y\in B$, $x\in f(B)$. If both are true simultaneously, then $f(A\cap B) \subseteq f(A) \cap f(B)$. 
        \item Assume that $x \in f^{-1}(A\cup B)$ Then, $f(x) \in A \cup B$. Since $f(x) \in A$ and $f(x) \in B$ and for all $A, B$ there exists a preimage, then $f^{-1}(A\cup B) \subseteq f(A) \cup f(B)$. The second inclusion is shown by the converse. Let $x\in f^{-1}(A) \cup f^{-1}(B)$. Since $f(x) \in A \cup B$ then $f^{-1}(A) \cup f^{-1}(B) \subseteq f^{-1}(A\cup B)$. Both inclusions are true, so there is an equality.
        \item Let $y \in f^{-1}(A\cap B)$ such that $f(y) \in A \cap B$. So, $f(y) \in A$ and $f(y)\in B$. Thus, $y \in f^{-1}(A)$ and $y \in f^{-1}(B)$. Or $y\in f^{-1}(A) \cap f^{-1}(B)$. So, $f^{-1}(A\cap B) = f^{-1}(A) \cap f^{-1}(B)$.
        \item Let $x \in f^{-1}(f(A))$. The inverse image of $f(A)$ will point to $A$ if $f$ is injective. Otherwise, it is at most a subset of $A$. $f^{-1}(f(A)) \supseteq A$ 
        \item Let $x \in f(f^{-1}(A))$. The image of the preimage is the identity if every element in $A$ is mapped to. Thus, the identity is equal if $f$ is surjective. 
    \end{enumerate}
\end{proof}

Remark that if $f$ is a bijective map, then $f^{-1}(f(A)) = f(f^{-1}(A))$.

\subsection{Problems}
\begin{problem}
    Let $\leq, \geq$ have their regular definitions. Let $A = \{0\leq x \leq 3, x \in \mathbb{R}\}, B = \{-1\leq x \leq 1, x \in \mathbb{R}\}$. Show that $A\cap B = C = \{0\leq x \leq 1, x \in \mathbb{R}\}$
\end{problem}

\begin{solution}
    To show this, we need to show that the LHS is equal to the RHS for the final line in the problem statement.  Trivially, $C \subset A$; $\inf C \in A, \sup C \in A$. Thus, $\forall x \in C, x \in A$. Similarily, $C \subset B$ by the same logic. Thus, state $C^c = (-\infty, 0) \cup (1, \infty)$. Furthermore, writing the union of elements in the compliments of $A, B$; $A^c \cup B^c = (-\infty, 0) \cup (1, \infty)$. We use the property of intersections of sets 
    \begin{align*}
        A^c \cup B^c &= (A \cap B)^c \\
                  C^c  &= (A \cap B)^c \\
                  C &= A \cap B
    \end{align*} 
    $\blacksquare$
\end{solution}

\begin{problem}
    List elements of;
    \begin{equation}
        \left(\{2,3,4\} \cup \{x\in \R: x^2 -4x +3 = 0 \}\right) \cap \{x\in \R:-1 \leq x < 3\}
    \end{equation}
\end{problem}
\begin{solution}
    The LHS of this contains two sets. The right-set are solutions to a quadratic equation. This contains two elements. 
    \[
    x_{1,2} = \frac{4 \pm \sqrt{16 - 12}}{2} = \{1, 3\}
    \]
    Thus, the LHS is the union of two sets. Rewriting this;
    \begin{equation}
       \{1,2,3,4\} \cap \{x\in \R:-1 \leq x < 3\}
    \end{equation}
    The intersection of the discrete set of integers between 1 and 4 and the open neighborhood between -1 and 3 is simply $\{1, 2\}$ as 3 is not included in the set. 
    \begin{equation}
        \left(\{2,3,4\} \cup \{x\in \R: x^2 -4x +3 = 0 \}\right) \cap \{x\in \R:-1 \leq x < 3\} = \{1,2\}
    \end{equation}
\end{solution}

\begin{problem}
    If $A \subset S$, show the following;
    \begin{enumerate}[label=\alph*.]
        \item  $(A^c)^c = A$
        \item $A\cup A = A\cap A = A \cup \emptyset = A$
        \item $A \cap \emptyset = \emptyset$
        \item $A \times \emptyset = \emptyset$
    \end{enumerate}
\end{problem}

\begin{solution}
    \begin{enumerate}[label=\arabic{*}.]
        \item Let $x\in A^c$. $x\notin A$. Thus, $(A^c)^c = A$.
        \item If $x\in A$ and $x \in A$ and $A$ is the same set, logically, the union of both sets is just the set. Similarily, the intersection with itself is just itself as all points are covered witin the same set. The set $\emptyset$ is defined as the set which contains nothing. Thus, $A \cup \emptyset$ is the union of the set $A$ with nothing. Since $\emptyset$ doesn't add anything new to the set, one logically writes that $A\cup \emptyset = A$.
        \item let $x\in A$ Since $x \notin \emptyset$ then $x \notin A \cap \emptyset$. However, nothing intersects with the emptyset, so naturally, $A\cap \emptyset = \emptyset$ as there is nothing to intersect over. 
        \item The cartesian product of the emptyset is again defined by the property of the emptyset having no elements. Since there is no ordered pair formed when taking the cartesian product with the emptyset, the logical output set is a set with no elements, which is the emptyset. 
    \end{enumerate}
\end{solution}

\begin{problem}
    Prove the following statements:
    \begin{enumerate}[label=\arabic{*}.]
        \item $A^c \cup B^c = (A \cap B)^c$
        \item $A \cap (B \cup C) = (A\cap B) \cup (A\cap C)$
        \item $A \cup (B \cap C) = (A\cup B) \cap (A\cup C)$
    \end{enumerate}
\end{problem}
\begin{problem}
    We prove each statement from top to bottom. To show equalities, we need to show that the LHS equates the the RHS.

    Let $x\in A\cap B$. Since $x$ is in both $A$ and $B$, then $x\notin A^c \cup B^c$. Thus, since $x$ is general; $A^c \cup B^c = (A \cap B)^c$. Similarily, let $x\in A^c \cup B^c$, then by logical, $x$ can be every value within except the points which overlap in $A$ and $B$ as their complements do not touch points which are contained in both sets. 

    Let $x\in A \cap (B\cup C)$ This set is in both $A$ and $(B\cup C)$. Thus, $x\in A, B\cup C \rightarrow, A, B \rightarrow, x \in (A\cap B)$. $x\in A, B\cup C \rightarrow, A, C \rightarrow, x \in (A\cap C)$. So, $x$ must be in one or the other. $A \cap (B \cup C) = (A\cap B) \cup (A\cap C)$

    Let $x\in A \cup (B\cap C)$, or $x$ is in $A$ or $B$ and $C$. Thus, we have two inclusions, $x \in A\cup B$, or its in $A$ or $B$ and $A \cup C$, or $A$ or $C$. Since $x$ must at least be in $A$, the left term is easy to see, however, if $x\in (B \cap C)$ it must be in both $B\cap C$. Thus, $A \cup (B \cap C) = (A\cup B) \cap (A\cup C)$.
\end{problem}

\section{Fields}

In real analysis, one tends to discuss the real-number system. This system, although intuitive in early math courses, must be built up from an abstract sense.

\begin{definition}
    A field, $F$, is a set along with the operations of addition and multiplication. Let $a,b,c$ be elements of $F$;
    \begin{enumerate}
        \item Commutativity: $a + b = b + a$
        \item Additivity: $(a + b) + c = a + (b + c)$
        \item Distributivity: $a(b + c) = ab + ac$
        \item Additive Identity: $a + 0 = a$
        \item Additive Inverse: $a + (-a) = 0$
        \item Multiplicative Identity: $1\cdot a  = a$
        \item Multiplicative Inverse: $a \cdot a^{-1} = 1$ 
    \end{enumerate}
\end{definition}

The rest is this section is treated as problems with proofs due to the nature of the subject.

Naturally, given one has proven that the additive inverse of 1 is -1 and that $-1 \cdot a = -a$, then one can define addition and subtraction;
\begin{enumerate}
\item Subtraction: $a-b$
\item Quotient: if $b\neq 0$, then $\frac{a}{b} = a b^{-1}$.
\end{enumerate}

\subsection{Ordered Fields}

An ordered field is defined by the notion of $a < b$ where $a,b \in P$ where $P$ defines a positive subset of a field. 

\begin{definition}\label{thm:ordered_field}
    An ordered field, $F$, is a field with a positive subset $P$ that abides by the following properties;
    \begin{enumerate}
        \item if $a \in F$ either $a=0$, $a \in P$, or $-a \in P$.
        \item if $a \in P$ then $-a \notin P$
        \item if $a,b \in P$ then $a + b \in P$.
    \end{enumerate}
\end{definition}

In addition, ordered fields have several properties that arise from these. For example, that of multiplicative inverse.
\begin{problem}
    Show that if $a\in P$, $a^{-1} \in P$.
\end{problem}
\begin{proof}
    Suppose that $a\in P$. Then, if $-a^{-1}$ were to be in $P$ one can check by closure of multiplicative inverse. Specifically, we can see if $-1 = a(-a^{-1}) \in P$ is true. This is a contradiction by bullet 2 of Def. \ref{thm:ordered_field}, which implies that $a^{-1}$ must be in an ordered set.
\end{proof}

The positive set $P$ can then be used to define operations on less than or larger than:
\begin{definition}
    The less than or larger than symbols are defined under elements of $P$. Suppose $F$ is an ordered field. Suppose $a,b \in F$;
    \begin{enumerate}
        \item if $ a < b$ than $b-a \in P$
        \item if $a\leq b$ than $a < b$ or $a = b$
        \item if $ a > b$ than $ b < a$
        \item if $a \geq b$ than $b < a$ or $a = b$
    \end{enumerate} 
\end{definition}

We can then prove transitivity;

\begin{problem}
    Show that an ordered field $F$ is transitive, that is, for elements $a,b,c \in F$, if $a < b$ and $b < c$ then $ a < c$.
\end{problem}
\begin{proof}
    By definition, $a < b$, then $b - a \in P$. Similarly, $c - b \in P$. Since $P$ is closed under addition, we have that $b - a + (c - b) = c - a \in P$. By definition, $a < c$.
\end{proof}

Next, we have the definition of absolute value. 
\begin{definition}
    Suppose $F$ is an ordered field and $b\in F$. The absolute value of $b$, denoted as $|b|$ is defined as:
    \begin{equation}
        |b| = 
        \begin{cases}
        b & \text{if }b \geq 0 \\ 
        -b & \text{if }b < 0 \\   
        \end{cases}
    \end{equation}
\end{definition}

The absolute value is a useful tool that allows use to define and prove the existence of the triangle inequality;
\begin{problem}
    Suppose $F$ is an ordered field and $a,b \in F$ show that 
    \begin{equation}
        |a + b| \leq |a| + |b|\,.
    \end{equation}
\end{problem}
\begin{proof}\label{proof:triangle_inequality}
    This can be shown in cases of the signs of each element.
    \begin{enumerate}
        \item $a, b > 0$; Then, $a + b \in P$ and by definition of the absolute value, $|a + b| = a + b = |a| + |b|$
        \item $a, b < 0$; If both terms are less than 0, then we can use the distributive property of multiplication: $|a + b| = |-(a + b)| = a + b = |a| + |b|$.
        \item $a < 0, b > 0$; Here, $a + b$ is not necessarily larger than 0. What matters is the output. If the sum of $a,b$ is negative, it falls into (2.) and if positive it falls into (1.). Otherwise, one can write that  if $b > a$, then $b + a < b$. By this logic, we have that $|b + a| < |b| < |b| + |a|$.
        \item $b < 0, a > 0$; Same as (3.).
        \item The logic of sum is if $a + b >0$, then $|a + b| = a + b$. if $a + b < 0$, then $|a + b| = -(a + b) = (-a) + (-b) \leq |a| + |b|$. 
    \end{enumerate} 
\end{proof}

Lastly, we can show that the ordered field of rational numbers $\mathbf{Q}$ as contained in each ordered field.
\begin{definition}
    Let $\varphi:\mathbf{Q} \rightarrow F$ such that $\varphi(0) = 0$ and;
    \begin{equation}
        \varphi\left(\frac{m}{n}\right) = \frac{\sum_{i=1}^{m} 1}{\sum_{i=1}^{n} 1}\,.
    \end{equation}
    As well as;
    \begin{equation}
        \varphi\left(-\frac{m}{n}\right) = \frac{\sum_{i=1}^{m} (-1)}{\sum_{i=1}^{n} 1}
    \end{equation}
\end{definition}
\begin{proof}
    First we show that this function is one-to-one, or surjective and bijective. Let $m,n,p,q$ be positive integers. We have that $\varphi(m/n) = \varphi(p/q)$ if;
    \begin{align*}
        (\sum_{i=1}^{m} 1)(\sum_{i=1}^{q} 1) &= (\sum_{i=1}^{p} 1)(\sum_{i=1}^{n} 1) \\
        mq &= pn\,.
    \end{align*}
    Thus, we have that $\frac{m}{n} = \frac{p}{q}$, which implies that for the rational functions this is fully one-to-one for all positive rational numbers.

    For negative rational numbers, we can use a similar logic. Let $m,p$ be negative rational numbers, we have that $-mq = -pn$ which shows that this function is one-to-one for all negative rational numbers. Thus, $\varphi$ is one-to-one on all of $\mathbf{Q}$.

    To verify that this map preserves properties of an ordered field, we can verify the properties one by one.
    \begin{enumerate}
        \item $\varphi(a + b) = \sum_{i=1}^{a + b} 1 = \sum_{i=1}^{a} 1 + \sum_{i=a+1}^{a + b} 1 = \sum_{i=1}^{a} 1 + \sum_{i=1}^{ b} 1 = \varphi(a) + \varphi(b)\,.$
        \item $\varphi(ab) = \sum_{i=1}^{ab} 1 = ab$. However, $\varphi(a) = a$ and $\varphi(b) = b$. so, $\varphi(a) \cdot \varphi(b) = ab = \varphi(ab)$.
        \item $\varphi(-a) = \sum_{i=1}^{a} -1 = -1 \cdot a = -a = -1 \cdot \varphi(a)\,.$
        \item $\varphi(a^{-1}) = \varphi(\frac{1}{a}) =\frac{1}{\sum_{i=1}^{a}} = \frac{1}{\varphi(a)}$.
    \end{enumerate}
\end{proof}
This results means that we can treat $\mathbf{Q}$ as a subset of the ordered field $F$ for all ordered fields.

\subsection{Completeness}

We start with the pythagorean theorem.
\begin{problem}
    Show that there is no rational number who's square is 2.
\end{problem}
\begin{proof}
    Let $m, n$ be integers such that there exists no common factor between them greater than 1. We aim to find a number $\left(\frac{m}{n}\right)^2 = 2$. Expanding the square, we have that $m^2 = 2 n^2$. It is clear that $m^2$ is even. Thus, $m=2k$ for some integer $k$. thus, $4k^2 = 2n^2$, or $2k^2 = n^2$. Thus $n^2$ is even as well. However, this is a contradiction as $m$ and $n$ are to have no common factors greater than 1. This is impossible if they are both even. Thus, there exists no $m,n$ that satisfy the above. This shows that the square root of $2$, $\sqrt{2}$ is a real number, that is not rational. 
\end{proof}
This shows that the ordered field of rational numbers, $\mathbf{Q}$, must have more properties to include a description of the real numbers.

\begin{definition}
    Suppose $F$ is an ordered field and $A$ is a subset of $F$; $A \subset F$. Then, let $b\in F$. The upper bound of $A$ is defined as $b$ such that for all $a \in A$, $a \leq b$. 

    The \textbf{least upper bound} is defined as $a \leq b$ such that;
    \begin{enumerate}
        \item $b$ is an upper bound of $A$.
        \item $b \leq c$ for all other upper bound $c \in F$.
    \end{enumerate}
\end{definition}

The existence of a least upper bound is so important that it has a name.
\begin{definition}
    An ordered field $F$ is called complete if every non-empty subset of $F$ that has an upper bound has a least upper bound.
\end{definition}

This is actually enough to define the real numbers.

\begin{definition}
    Let $\mathbf{R}$ define a complete ordered field. $\mathbf{R}$ is known as the field of real numbers.
\end{definition}

\begin{problem}

\end{problem}
\begin{proof}

    \begin{align*}
        0 &= 0\,,
        0 + 0 = 0\,.
    \end{align*}
    Using this property, one can use the distributivity of the field $F$ to show that;
    \begin{align*}
        a0 &= a(0 + 0)\,\\
        &= a0 + a0\,.\\
    \end{align*}
    Using the additive inverse, 
    \begin{equation}
        0 = a0\,
    \end{equation}
    which concludes the proof.
\end{proof}

\begin{problem}
    Show the following. Let $F$ be a field. 
    \begin{itemize}
        \item For each $a \in F$, show that the additive inverse of $a$ is unique.
        \item $-(-a) = a$ for each $a \in F$.
        \item $(-1)a = -a$ for each $a \in F$. 
    \end{itemize}
\end{problem}
\begin{proof}
    The three proofs are shown in order.
    \begin{itemize}
        \item Let $a,b,c \in F$ such that $a + b = 0$ and $a + c = 0$. Then, if both of these equations are equal to 0, one can set them to be equal. That is,
        \begin{align*}
            a + b = a + c\,.
        \end{align*}
        The additive inverse of $a$, which is $-a$ can be added to both sides, which implies that;
        \begin{equation*}
            b = c\,.
        \end{equation*}
        However, since $b$ is the additive inverse by definition, there is at most $1$ additive inverse of $a$, which is defined as $-a$. 
        \item Let $a \in F$. Let $b \in F$ such that $ab = (-a)$. Using the multiplicative inverse,
        \begin{align*}
            ab \cdot a^{-1} &= (-a) \cdot a^{-1}\,,\\
            \text{distributivity} & \\
            b a a^{-1} &= -(a a^{-1})\,,\\
            b &= -1\,.
        \end{align*}
        Thus, using the definition of the additive inverse, one finds that;
        \begin{align*}
            a + (-a) &= 0\,,\\
            -a + -(-a) &= -1 \cdot 0\,,\\
            -a + -(-a) &= 0\,,\\
            -a + a + -(-a) &= a \,,\\
            -(-a) &= a\,.
        \end{align*}
        which concludes the proof. We have also shown that since $b$ is unique, there is a $b$ that exists and $ba = -a$.
    \end{itemize}
\end{proof}

\section{The Real Number System}

The real numbers are defined by a set of axioms. There are various ways to treat this. I am going to just state all of the properties upfront and then proceed with the consequences of their existence. 

\subsection{Axioms and Order}

\begin{theorem}
    \label{thm:realnumber}
    \textbf{Axioms of the Real Number System:} These are the axioms that define the set of real numbers. The properties are stated outright, then the consequences are listed in further statements.
   
    \begin{enumerate}[label=F\arabic{*}:]
        \item \textbf{Commutativity}; Let $a, b \in \R$, then $a + b = b + a$, and $a \cdot b = b \cdot a$. 
        \item \textbf{Associativity}; Let Let $a, b, c \in \R$, then $(a + b) + c = a + (b + c)$, and $a \cdot (b \cdot c) = (a\cdot b) \cdot c$.
        \item \textbf{Distributitivity}; $a \cdot (b + c) = ab + ac$
        \item \textbf{Existence of Neutral Numbers}; $a + 0 = a$, $a \cdot 1 = a$
        \item \textbf{Existence of Additive and Multiplicative Inverse Numbers}; For any $a 
         \in \R$ there exists a number $b$ such that $a + b = 0$, where $b = -a$. Simiarily, there exists a number $c$ such that $a \cdot c = 1$, where $c = a^{-1}$.
    \end{enumerate}
    \begin{enumerate}[label=O\arabic{*}:]
        \setcounter{enumi}{5}
        \item \textbf{Order}; There is a subset of $\R$ known as $\R_+$ such that the two properties are satisified:
        \begin{itemize}
            \item If $a, b \in \R_+$, $a + b \in \R_+$, $a \cdot b \in \R_+$. 
            \item For any $a \in \R$ only one of the following is true. \[a\in \R_+,\quad a = 0,\quad -a \in \R_+\]. 
        \end{itemize}
        The numbers such that $a \in \R_+$ are known as positive numbers, while the numbers such that $-a \in \R_+$ are known as negative numbers. 
    \end{enumerate}
    \begin{enumerate}[label=LUB\arabic{*}:]
        \setcounter{enumi}{6}
        \item \textbf{Least Upper Bound}; A nonempty set of real numbers that is bounded from above will have a least upper bound. 
    \end{enumerate}
\end{theorem}

The real number system is completely defined by the Thm. \ref{thm:realnumber}. We can now form the properties and rules of algebra on the real number system. 

\begin{enumerate}
    \item In a sum or product of many numbers, the parentheses can be omitted; $(a + (b + c)) + d = a + ((b + c) + d) = (a + b) + (c + d) = \dots$ by F1 and F2.
    \item  In a product of many numbers, order is immaterial; $a \cdot b \cdot c = b \cdot a \cdot c = c \cdot a \cdot b = \dots$
    \item For any $a,b \in \R$ the equation $x + a = b$ has one and only one solution. For, if $x\in \R$ then see the following computation.
    \begin{align*}
        x &= x + 0\\
        &= x + ((a) + (-a))\\
        &= (x + a) +(- a)\\
        &= b + (-a) \\
        x &= b + (-a)
    \end{align*}
    Thus, $x = b + (-a)$ is the only solution.
    \item For any $a,b \in \R$, with exception $a\neq 0$ the equation $xa = b$ has one and only one solution.
    \begin{align*}
        x &= xa a^{-1} \\
        &= (x a) \cdot a^{-1} \\
       x &= b a^{-1} 
    \end{align*}
    Thus, the element 1 is unique from F4. we define $a^{-1} = \frac{1}{a}$

    \item For any element $a\in R$, $a \cdot 0 + a \cdot 0 = a\cdot (0 + 0) = a \cdot 0 = a \cdot 0 + 0$. So both $a \cdot 0$ and $0$ are solutions of the equation $x + a \cdot 0 = 0$. Thus, if a product of numbers is 0 then at least one of the element must be 0. for if $ab = 0$ and $a\neq 0$ then we can multiply both sides by $a^{-1}$ to get $b = 0$. Hence, the illegitimacy of division by 0. 
    \item Solutions of the equation $x + (-a) = 0$ are given by $-(-a)$ given by (3.). By F5, we have $-(-a) + (-a) = 0$, so $-(-a) = a$ for any $a \in \R$.
    \item $(a^{-1})^{-1} = a$ for any non-zero $a \in \R$.  Since $a \cdot a^{-1} = 1$ by F5,  and we know that $a^{-1} \neq 0$, then F4 implies that  $(a^{-1})^{-1}$ and $a$ are equal as both are solutions to $x + a^{-1} = 1$.
    \item $-(a+b) = (-a) + (-b)$ for all $a,b \in \R$ as both are solutions to the equation $x + (a + b) = 0$. 
    \item $(ab)^{-1} = a^{-1} b^{-1}$ for any $a,b \in \R$, $a,b \neq 0$. Both are solutions to the equation $x(ab) = 1$. 
    
    From this, we can define the rules of the fraction;
    \begin{align*}
        \frac{ac}{bc} &= ac (bc)^{-1} = ab^{-1} c c^{-1} = ab^{-1} = \frac{a}{b} \\
        \frac{a}{b} \cdot \frac{c}{d} &= ab^{-1} c d^{-1} =ac (bd)^{-1} = \frac{ac}{bd} \\
        \frac{a}{b} + \frac{c}{d} &= ab^{-1} + cd^{-1} =ab^{-1}d d^{-1} + c b b^{-1} d^{-1} \\
        &= (ad + cb) \cdot (b^{-1} d^{-1}) = \frac{ad + cb}{bd}
    \end{align*}
    \item $a \cdot (-1) = -a$ for all $a\in \R$. Since $(-1) \cdot a + a = a((-1) + 1) = a \cdot 0 = 0$. We have that $(-1) \cdot a$ and $a$ are solutions to the equation $x + a = 0$, hence are equal. 
    
    A consequence of this is that $-a \cdot b = (-1) \cdot a \cdot b = -ab$ and $(-a) \cdot (-b) = (-1) \cdot (-1)\cdot  a\cdot b = ab$
\end{enumerate}

These are the field properties of the real numbers and apply to fields such as the rational and complex numbers. To define the reals, The order and LUB properties need to be applied. We can now discuss the order properties of the real numbers. 

\begin{enumerate}
    \item If $a,b \in \R$ only one of the following statements is true;
    \begin{align*}
        a &< b \\
        a &= b \\
        a &> b \\
    \end{align*}
    This is the case as we apply $(a-b)$ then the number must fit in one of three subsets, being $a\in \R_+, -a \in \R_+, a\in \{0\}$.
    \item if $a >b$ and $b>c$ then $a-b \in \R_+$ and $b - c\in R_+$. Thus, $a - c = (a-b) + (b-c) \in \R_+$. So, $a > c$.
    \item If $a > b$ and $c \geq d$, then $ a + c \geq b + d$. This implies that $a - b \in \R_+, c - d \in \R_+ \cup \{0\}$. Thus, $(a+c) - (b+d) = (a-b) + (c-d) \in \R_+$.
    \item If $a > b > 0$ and $c \geq d > 0$, then $ac > bd$. For $a-b \in \R_+$ and $c \in \R_+$, then $ac - bc = (a-b)c \in \R_+$. Similarily, $c-d \in \R_+ \cup \{0\}$, $b\in\R_+$, and so $bc - bd \in \R_+ - \{0\}$. Thus, it follows that $ac - bd = (ac - bc) + (bc- bd) \in \R_+$, that is, $ac > bd$.
    \item \textbf{Rules for addition and multiplication of real numbers;} 
    \begin{itemize}
        \item $(a_+) + (a_+) = (a_+)$
        \item $(a_-) + (a_-) = (a_-)$
        \item $(a_+) \cdot (a_+) = (a_+)$
        \item $(a_-) \cdot (a_-) = (a_+)$
        \item $(a_+) \cdot (a_-) = (a_-)$
    \end{itemize}
    \item For any $a \in \R, a^2 \in \R_+$. More tightly, $a^2 \geq 0$ where the equality is $0^2 = 0$ and special exceptions are $1^2 = 1$.
    \item If $a>0$, then $1/a >0$. 
    \item If $a > b >0$ then $1/b > 1/a$.
\end{enumerate}

\subsection{Least Upper Bound Property.}

The final concept for the real number system is the property of the least upper bound (LUB). If $S \subset \R$, then an upper bound for the set $S$ is a number $a\in \R$ such that $s \leq a$ for each $s \in S$. If such a number exists, $S$ is bounded from above. We call a real number $y$ a \textbf{least upper bound} of the set $S$ if $y$ is an upper bound for $S$, and if $a$ is any given upper bound for $S$, then $y \leq a$. 

A non-empty, finite subset $S \subset \R$ will always have a LUB. We need to justify \textit{LUB7}, which states that a non-empty set of real numbers, bounded from above, will always have a LUB. 

The consequences of the LUB are listed;
\begin{enumerate}[label=\arabic{*}.]
    \item For any real number $x$, there an an integer such that $n > x$. 
    \begin{proof}
        By contradiction, suppose there is a number that doesn't obey this. Then, $n \leq x$ and thus is bounded from above. Since The set of integers is non-empty and bounded from above by the number $a$. However, for each integer $n$, $n+1$ is aso an integer. So, $n + 1 \leq a$. Thus, $n \leq a-1$ is also an upper bound. Since $a -1 < a$, $a-1$ is not an upper boumd, hence this is a contradiction. 
    \end{proof}
    \item For any positive number $a$ there exists an integer $n$ such that $\frac{1}{n} < a$. 
    \begin{proof}
        Since $a \in \R$, by the field property, $a^{-1} = 1/a \in \R$. Since we prove that for all real numbers, there exists $n>x$ we have that there exists integer $j > a$ such that $1/a > 1/j$ by the order property. Hence, $1/j > 0$.
    \end{proof}
    \item For any $x\in \R$, there is an integer $n$ such that $n \leq x < n+1$.
    \begin{proof}
        Let $N$ be an integer such that $|N| > x$. Then, we have that $x$ is bounded by the inequality $-N < x < N$. We have that this forms the set $\{-N, -N + 1, \dots , 0, 1, 2, \dots, N\}$. We can choose $n$ arbitraily along this such that $n \leq x < n+1$
    \end{proof}
    \item For any $x\in \R$ and positive integer $N$ there is an integer $n$ such that \[\frac{n}{N} < x < \frac{n+1}{N}\]
    \begin{proof}
        We can first rewrite this equation by multiplying each set by $N$, \[n < Nx < n+1\]
        We need to show that $N\cdot x \in \R$. Since $x\in \R$ and $N \in \mathbb{Z} \subset \R$ we have that $x\cdot N \in \R$ by the field properties. Thus, let $y = Nx \in \R$, by (3.) we have \[n \leq y < n + 1\]
    \end{proof}
    \item if $x, a \in \R, a > 0$ then there exists a rational number $r$ such that $|x - r| < a$. That is, we can approximate a real number as closely as we wish by a rational number.
    \begin{proof}
        We first use (2.) to find a positive integer $n$ such that $\frac{1}{n}< a$. By (4.) we can use that for $x$ there exists $\frac{n}{N} < x < \frac{n+1}{N}$. Rewriting this by subtracting $n/N$; 
        \begin{align*}0 < x - \frac{n}{N} &< \frac{1}{N} \\
        &\quad \quad \quad < a\end{align*}
        Thus, We have that $|x - \frac{n}{N}| < a$
    \end{proof}
\end{enumerate}

\subsection{Square Roots}

We will discuss the Schwarz inequality as it is useful later;
\begin{definition}
    The Schwarz inequality is defined as
    \begin{equation}
        |a_1b_1 + a_2b_2 + \dots + a_nb_n| \leq \sqrt{a_1^2 + a_2^2 + \dots + a_n^2}  \sqrt{b_1^2 + b_2^2 + \dots + b_n^2}
    \end{equation}
\end{definition}
\begin{proof}
    We start with the fact that
    \begin{equation}
        0 \leq (\alpha a_1 - \beta b_1)^2 + (\alpha a_2 - \beta b_2)^2 + \dots + (\alpha a_n - \beta b_n)^2
    \end{equation}
    the goal of writing this equation is to factor it out into the RHS. We can multiple each term out;
    \begin{align*}
        0 &\leq (\alpha a_1 - \beta b_1)^2 + (\alpha a_2 - \beta b_2)^2 + \dots + (\alpha a_n - \beta b_n)^2\\
        &= \alpha^2(a_1^2 + a_2^2 + \dots) + \beta^2(b_1^2 + b_2^2 + \dots)- 2\alpha\beta(a_1b_1 + a_2b_2+\dots)
    \end{align*}
    We can let $\beta = \sqrt{a_1^2 + a_2^2 + \dots}, \alpha = \sqrt{b_1^2 + b_2^2 + \dots}$ to add the square terms together; 
    \begin{align*}
        0 &\leq 2 (b_1^2 + b_2^2 + \dots) (a_1^2 + a_2^2 + \dots) - 2\alpha\beta(a_1b_1 + a_2b_2+\dots)\\
        (a_1b_1 + a_2b_2+\dots)&\leq \frac{1}{\alpha\beta}(b_1^2 + b_2^2 + \dots) (a_1^2 + a_2^2 + \dots) \\
        &= \sqrt{a_1^2 + a_2^2  + \dots}\sqrt{b_1^2 + b_2^2 + \dots} 
    \end{align*}
    or,
    \begin{equation}
        |a_1b_1 + a_2b_2+\dots +a_nb_n|\leq \sqrt{a_1^2 + a_2^2  + \dots+a_n}\sqrt{b_1^2 + b_2^2 + \dots+b_n} 
    \end{equation}
\end{proof}
As a corollary, note that using the property of the absolute value, 
\begin{definition}
    \begin{equation}
       \sqrt{\sum_j (a_j - b_j)^2 } \leq  \sqrt{\sum_j a_j^2 } + \sqrt{\sum_j b_j^2 }
    \end{equation}
\end{definition}
\begin{proof}
    \begin{align*}
        \sum_j (a_j - b_j)^2  &= \sum_j a_j^2 + b_j^2 - 2a_jb_j \\
        &= (a_1^2 + \dots) + (b_1^2 + \dots) - 2(a_1b_1 + a_2b_2 + \dots)\\
        \text{Schwarz }&\leq(a_1^2 + \dots) + (b_1^2 + \dots) +2\sqrt{a_1^2 +\dots}\sqrt{b_1^2 +\dots}\\
        &=\left[\sqrt{a_1^2 + \dots} + \sqrt{b_1^2 + \dots}\right]^2
    \end{align*}
    Thus, we have shown that;
    \begin{equation}
        \sqrt{\sum_j (a_j - b_j)^2}\leq \sqrt{a_1^2 + a_2^2+ \dots+ a_n^2} + \sqrt{b_1^2 + b_2^2+ \dots+ b_n^2}
    \end{equation}
\end{proof}

\section{Metric Spaces}

A metric space is defined as a set $E$ with a rule $d(q,p)$ $\forall q, p \in E$. If $d$ satisfies
\begin{equation}
    \begin{aligned}
        d(q,p) &\geq 0,\\
        d(q, p) &= 0, \quad \text{iff. }q=p, \\
        d(q,p) &= d(p, q), \\
        d(q,r) &\leq d(q, p) + d(p, r).
    \end{aligned}
\end{equation}
\begin{example}
Let $E = \R$ with rule $d(q, p) = |q-p|$. 
The first three properties are trivial. 
\begin{proof}
    We aim to show that 
    \begin{equation*}
        |q - r| \leq |q - p| + |p - r|
    \end{equation*}
    This proof utilizes the property of the absolute value;
    \begin{equation}
        |a + b| \leq |a| + |b|
    \end{equation}
    Thus, 
    \begin{align*}
        |q - r| &= |q + p - p - r| \\
        &= |(q-p)  + (p - r)| \\
        &\leq |(q-p)|  + |(p - r)| \\
        &= |q - p| + |p - r|
    \end{align*}
\end{proof} 
Thus, $E = \R$ is a metric space. 
\end{example}


\begin{example}
    Let $E^n = \R^n$ with rule $d(x, z) = \sqrt{(x_1 - z_1)^2 + (x_2 - z_2)^2 + \dots + (x_n - z_n)^2}$. 
    \begin{proof}
        As before the first three properties are trivial. The triangle inequality is proven by using the Schwarz inequality and it's corollary;
        \begin{align*}
            \sqrt{\sum_j (x_j - z_j)^2} &=  \sqrt{\sum_j (x_j - p_j+p_j - z_j)^2} \\
            &=  \sqrt{\sum_j ((x_j - p_j)+ (p_j - z_j))^2} \\
            &=  \sqrt{\sum_j (a_j+ b_j)^2} \\
            &\leq \sqrt{\sum_j a_j^2} +\sqrt{\sum_j b_j^2} \\
            &= \sqrt{\sum_j (x_j - p_j)^2} +\sqrt{\sum_j (p_j - z_j)^2} \\
        \end{align*}
        This shows;
        \begin{equation}
            d(x,z) \leq d(x, p) + d(p, z)
        \end{equation}
    \end{proof}
    Thus, $E^n$ is a metric space. 
\end{example}


\section{Polynomials}

The polynomial function is defined as a map consisting of a sum of indeterminant variables $x$, meaning they are not yet known or determined, raised to an positive integer power. The degree of the polynomial is defined by the power leading of the leading term. Let $x\in \R$ and $f$ be a map. The general polynomial function of the $n$-th degree is defined as;
\begin{equation}
    f(x) = \sum_{j=0}^{n}a_j x^j
\end{equation}
where $a_j$ are real-valued constants. The degree of $n$ fixes the leading constant to be non-zero, $a_n \neq 0$.

The polynomials of first and second degree, known as the linear and quadratic forms, are most famous and widely used. These functions are used so much that they are taught in high-school as introductory mathematics. 

\begin{definition}
    Let $x\in\R$ and the constants $a_1$ and $a_0 \in \R \setminus 0$. The linear map, $f:\R \rightarrow \R$ is defined as
    \begin{equation}
        f(x) = a_1 x + a_0
    \end{equation}
    where $a_1$ is defined as the slope of the line, and $a_0$ is defined as the intercept of the line. 
\end{definition} 



\begin{definition}
    Let $x\in\R$ and the constants $a_2$, $a_1$, and $a_0 \in \R$. The standard-form of the quadratic map, $f:\R \rightarrow \R$ is defined as
    \begin{equation}
        f(x) = a_2x^2 + a_1 x + a_0
    \end{equation}
    where $a_2 \in \R \setminus 0$ and $a_1$ and $a_0 \in \R$. The quadratic form can be factored in various ways to describe different properties of it. The vertex-form is defined as
    \begin{equation}
        f(x) = a_2(x-h)^2 + k
    \end{equation}
    where the substitutions $h$ and $k$ define the position of the vertex. These constants, easily derived using a derivative, are given as
    \begin{equation}
        h = -\frac{a_1}{2a_2}\,, \quad k = a_0 - \frac{a_1^2}{4a_2}\,.
    \end{equation}
\end{definition} 

The solutions of a univariate polynomial, known as the roots, exist if and only if $f(z) = 0$ for a polynomial solution $z$. If a polynomial has $N$ solutions $z_i$, the form of the factored polynomial simply exists as
\begin{equation}
    f(x) = c(x-z_n)(x-z_{n-1}) \dots (x-z_2)(x-z_1)
\end{equation}
where $z_i$ can be a complex number. In the case of positive coefficients only, there exists at most $n$ solutions. 

To factor a polynomial, 
\begin{equation}
f(x) = a_n x^n a_{n-1}x^{n-1}+ \dots +a_1 x + a_0\,,
\end{equation}
the rational root test can be used where $a_i \in \mathbf{Z}$ and $a_n, a_0 \neq 0$. The rational root theorem states that candidate numbers $q$ can be defined as 
\begin{equation}
    q = \frac{p}{q}\,,
\end{equation}
such that $p$ is an integer factor of $a_0$ and $q$ is an integer factor of $a_n$. Thus, all possible roots consist candidates $q$ for all factors $p, q$.

The applications of the polynomials are wide. For example, see Gaussian integrals, Legendre polynomials, and free-energy landscapes, where quadratic solutions are generally made to ensure Gaussianeity.
