\section{Measurable Spaces}

A measurable space is a pair of a set $E$ and a set of subsets of $E$ which we will refer to as $\varepsilon$. We first consider the set $E$ as a mathematical object. We would like do perform mathematical operations on this. The set, given that it allows these operations, should be closed under them. This is the fundamental motivation for a measurable space.

Consider then the set $E$ being finite. We would like to ensure that this set is closed under finite union. This implies that for a subset $A_i \subset E$,
\begin{equation}
	\forall A_i \in E, \quad \bigcup_i A_i \in E\,.
\end{equation}
This implies that the unions of two subsets will form a new subset which is already contained in $E$. This idea is defined in detail as an \textit{algebra}.

\begin{definition}
	An algebra on the set $E$ is defined as a non-empty collection of sets $\varepsilon$ which is closed under finite union and complement.
	\begin{align*}
		\mathrm{if }A \in \varepsilon, &\quad\mathrm{then} \quad A^c \in \varepsilon\,,\\
		\mathrm{if }A, B \in \varepsilon, &\quad \mathrm{ then}\quad A\cap B \in \varepsilon\,.\\
	\end{align*}
\end{definition}
For a finite set $E$, the set itself and its complement must be included in the algebra;
\begin{equation}
	E\in \varepsilon, \quad \emptyset \in \varepsilon\,.
\end{equation}

\subsection{Sigma-algebras}

A sigma-algebra is a special kind of algebra which is closed under complements and countable unions.
\begin{definition}
	A non-empty collection of subsets $\sigma_E$, which consist of measurable sets $E_i$, is known as a sigma-algebra on $E$ if 
	\begin{enumerate}
		\item $A \in \sigma_E,  \quad \rightarrow E\setminus A \in \sigma_E\,,$
		\item $A_1, A_2, \dots \in \sigma_E, \quad \rightarrow \bigcup_n A_n \in \sigma_E\,.$
	\end{enumerate}
	Some properties are that every sigma-algebra on $E$ contains at least $E$ and $\emptyset$. That is the simplest sigma-algebra is $\sigma_E = \{E, \emptyset\}$.
\end{definition}

Since a sigma-algebra is fundamentally a collection of sets, one can intersect a family of sigma-algebras on $E$, which when generates again a sigma-algebra on $E$. 

For example, consider an arbitrary collection of subsets of $E$, $\mathcal{C}$. Then, a sigma-algebra which contains $\mathcal{C}$ can be generated. Suppose that $\mathcal{C}$ contains finite countable elements $C_i$, then the sigma algebra would be constructed by the following;
\begin{equation}
	\sigma = \{E, \emptyset, C_i, C_i \cup C_j, \dots, C_i^c, \dots\}\,,
\end{equation}
which specifically consists of all elements of $\mathcal{C}$, as well as ensuring closure under complement and union. 

Another such example is known as the power set, or the sigma-algebra consisting of each and every possible subset of $E$. To imagine this, consider a partition into 3 components. The explicit power set is then;
\begin{equation}
	2^E = \{C_1\cup(C_2 \cup C_3), C_1 \cup C_2, C_1 \cup C_3, C_2 \cup C_3, C_1, C_2, C_3, \emptyset \}\,.
\end{equation}
The set $E$ contains 3 partitions, which is expressed as $2^3 = 8$ elements in the power set. The proof for this can be done via induction. An intuitive explanation is the fact that the set operation $\cup$ acts between 2 elements without parity. Thus, for all possible unions of 3 elements, there are 3 possible combinations. For 4 elements, there are 6 combinations. in addition, one must add the higher order additions as well.  As one can see, this is related to the sum of all subsets with $k$ connections. 

Given a set of $n$ elements, the size of the power set will consist of the sum of all possible subsets. This contains the combinatoric collection of unions between each of union-orders. By the binomial theorem;
\begin{equation}
	\sum_{k=0}^n \frac{n!}{k!(n-k)!} = (1+1)^n = 2^n\,.
\end{equation}

Returning to $\mathcal{C}$, if one takes all sigma-algebras that contain $\mathcal{C}$ and intersect them, they will arrive at the smallest possible sigma-algebra that contains $\mathcal{C}$, which is known as the generator of $\mathcal{C}$ and is denoted $\sigma\mathcal{C}$.

Remarks; the countable intersection of two (or more) sigma-algebra is again a sigma-algebra. The the union of two (or more) sigma-algebras is not necessarily a sigma-algebra.
\begin{proof}
	By example, let $\Omega$ be a set and $A,B \subset \Omega$. The sigma-algebra $\mathcal{F}_i$ consists of 
	\begin{equation}
		\mathcal{F}_1 = \{\emptyset, \Omega, A, A^c\}\,,
	\end{equation}
	and
	\begin{equation}
		\mathcal{F}_2 = \{\emptyset, \Omega, B, B^c\}\,.
	\end{equation}
	The intersection of the two is simply the $\{\emptyset, \Omega\}$ is the simplest sigma-algebra by definition. 

	The union of the two, $\mathcal{F}_3 = \mathcal{F}_1 \cup \mathcal{F}_2$;
	\begin{equation}
		\mathcal{F}_3 = \{\emptyset, \Omega, A, A^c, B, B^c\}\,,
	\end{equation}
	is not closed under finite union or complement as $A \cup B \notin \mathcal{F}_3$. 
\end{proof}
It should be noted that the \textbf{uncountable intersection} of sigma-algebras are also sigma-algebras.


\subsection{p, d systems}

A collection of subsets $\mathcal{P}$ is a p-system if it is closed under intersection. 

A collection of subsets $\mathcal{D}$ is a d-system if it satisfies the following properties;
\begin{enumerate}
	\item $E\in \mathcal{D}$,
	\item $A, B \in \mathcal{D}$ and $A\supset B$ then $A\setminus B \in \mathcal{D}$,
	\item $(A_n) \subset \mathcal{D}$ and $A_n \nearrow A$ then $A\in \mathcal{D}$,
\end{enumerate}

The notation $(A_n)$ denotes a sequence. The notation $A_n \nearrow A$ implies that as the sequence continues, the limit of the sequence approaches the value of $A$. 

\begin{definition}
	A collection of subsets of $E$ is a sigma-algebra if and only if it is both a p-system and a d-system on $E$.
	\begin{proof}
		To prove this statement, it is trivial that a sigma-algebra satisfies all of the criteria of both p and d systems. Thus, it is our task to show the converse.

		Let the collection $\mathcal{E}$ on $E$ be both a p-system and a d-system. It is closed under intersection. We require for it to be a sigma-algebra that is it closed under finite union and complement. 
		
		Since $\mathcal{E}$ is a d-system, it contains $E$ and is closed under set subtraction. By clause 2 of the d-system, 
		\begin{align*}
			A \in \mathcal{E}, \rightarrow E\setminus A \in \mathcal{E}\,,
		\end{align*}
		which implies that $E^c \in \mathcal{E}$. This can be repeated for any element $E_i = E_k \cup E_j, E_k, E_j \in \mathcal{E}$. 
		
		Since $\mathcal{E}$ is closed under complement and intersection $(A^c \cap B^c) \in \mathcal{E}$. Thus, since this is closed under complement, then the complement is in $\mathcal{E}$:
		\begin{equation}
			(A^c \cap B^c) = (A \cup B)\,,
		\end{equation}
		which is precisely closure under union by the property of being a p-system.

		This idea is extended to finite unions as given a sequence $(A_n) \subset \mathcal{E}$, then one can define a sequence $B_1 = A_1, B_2 = A_1 \cup A_2, \dots$. Since here $B_n \nearrow \bigcup_n A_n$, then by clause 3 of the d-system, $\bigcup_n A_n \in \mathcal{E}$.
	\end{proof}
\end{definition}

\begin{definition}
	Let $\mathcal{D}$ be a d-system on $E$. Fix $D$ in $\mathcal{D}$ and let 
	\begin{equation}
		\hat{\mathcal{D}} = \{A\in \mathcal{D}: A\cap D \in \mathcal{D}\}\,.
	\end{equation}
	Then, $\hat{\mathcal{D}}$ is again a d-system.
\end{definition}
\begin{proof}
	To show that $\hat{\mathcal{D}}$ is a d-system on $E$ it is sufficient to check all of its requirements. Firstly, the set notation is written as all elements $A$ in $\mathcal{D}$ such that $A \cap D \in \mathcal{D}$. Naturally, this implies that $E \in \hat{\mathcal{D}}$. $E\in \mathcal{D}, E\cap D = D, D \in \mathcal{D}$.
	
	To show set subtraction on $\hat{\mathcal{D}}$, note that for all $A,B \in \mathcal{D}$ such that $A\supset B$, $A\setminus B \in \mathcal{D}$. By definition, all elements with an intersection between $A$ and $D$ are in the set $\hat{\mathcal{D}}$. This implies that all elements $A,B \in \hat{\mathcal{D}} \supset \mathcal{D}$. Since $A,B \in \mathcal{D}$, then $A\setminus B \in \mathcal{D}$ by the definition of a d-system.

	Lastly, consider a sequence $(A_n)$. It is sufficient to show that the union of this sequence is contained in $\hat{\mathcal{D}}$. 
	\begin{align*}
		\hat{\mathcal{D}} &= \{\cup_nA_n \in \mathcal{D}\} \& \{\cup_nA_n \cap D \in \mathcal{D}\} \\
		&= \{\cup_nA_n \in \mathcal{D}\} \& \{\cup_n(A_n \cap D) \in \mathcal{D}\} \\
	\end{align*}
	Since $A_n \cap D \in \mathcal{D}$ by the property of the d-system, then $A\in \hat{\mathcal{D}}$.
\end{proof}

The next property is known as the Monotone class theorem. 
\begin{definition}
	If a d-system contains a p-system, it also then contains the sigma-algebra generated by that p-system.
	\begin{proof}
		Let $\mathcal{C}$ be a p-system. Let $\mathcal{D}$ be the smallest d-system on $E$ that contains $\mathcal{C}$. We want to prove $\mathcal{D} \supset \sigma\mathcal{C}$.
		It is sufficient to show that $\mathcal{D}$ is a sigma-algebra, however, since a d-system is a sigma-algebra if and only if it is both a d and p system, it is necessary to show that $\mathcal{D}$ is also a p-system.

		We aim to show closure under intersection.

		Let $B$ be fixed in $\mathcal{C}$;
		\begin{align*}
			\mathcal{D}_1 = \{A \in \mathcal{D}: A \cap B \in \mathcal{D}\}\,.
		\end{align*}
		By the previous lemma, since $B\in \mathcal{D}$, $\mathcal{D}_1$ is a d-system.
		Similarly, for a fixed $A \in \mathcal{D}$,
		\begin{align*}
			\mathcal{D}_2 = \{B \in \mathcal{D}: A \cap B \in \mathcal{D}\}\,,
		\end{align*}
		which is a d-system as $B \in \mathcal{D}$. The key here is that since $\mathcal{C}$ is contained in $\mathcal{D}$, the set $B$ is in $\mathcal{D}$. Also, $\mathcal{D}_1$ is a d-system that contains $\mathcal{C}$ if $A\in \mathcal{C}$ and $B \in \mathcal{C}$ then $A\cap B \in \mathcal{C}$ under closure. Thus, $\mathcal{D}_1$ must be the smallest  d-system containing $\mathcal{C}$, or $\mathcal{D}_1 \supset \mathcal{D}$. In other words, $A \cap B \in \mathcal{D}$ for all $A,B \in \mathcal{C}$.

		Thus, $A\cap B \in \mathcal{D}$ whenever $A$ and $B$ are in $\mathcal{D}$. This implies closure under intersection, which implies $\mathcal{D}$ is a p-system.
	\end{proof}
\end{definition}



\subsection{Problems}

\begin{problem}
	Prove that if $\varepsilon$ is an algebra on $E$, then 
	\begin{enumerate}
		\item $E \in \varepsilon$
		\item $\emptyset \in \varepsilon$
	\end{enumerate}
\end{problem}

\begin{solution}
	Since $\varepsilon$ is a non-empty set, and is an algebra, it is closed under finite union. Thus, since $E$ is a finite set, one can partition $E$ into a finite number of elements $E_i$. Under the closure of finite union, 
	\begin{equation}
		\bigcup_i E_i \subseteq E\,,
	\end{equation}
	which is necessarily an element of $\varepsilon$.

	Another proof here is that given $E$ is non-empty, $E_i$ exists. By the definite of $\varepsilon$ the complement of this is also in the set $\varepsilon$. Thus, under the finite closure of the union, $E_i \cup E_i^c \in \varepsilon$. Note here that $E_i \cup E_i^c = E$, which implies that $E\in \varepsilon$.

	Similarly, single the algebra is closed under finite complement, one can use the fact that $E\in \varepsilon$;
	\begin{align*}
		E\in \varepsilon\\
		E^c \in \varepsilon\\
		E^c = \emptyset\\
		\emptyset \in \varepsilon
	\end{align*}
\end{solution}

\begin{problem}
	Partition generated by a $\sigma$-algebras.
	\begin{enumerate}
		\item Let $\mathcal{C} = \{A,B,C\}$ be a partition of $E$ List all the elements of $\sigma \mathcal{C}$
		\item let $\mathcal{C}$ be a countable partition of $E$. show that every element of $\sigma \mathcal{C}$ is a countable union of elements taken from $\mathcal{C}$.
		\item Let $E = \mathbb{R}$. Let $\mathcal{C}$ be the collection of all singleton subsets of $\mathbb{R}$, that is, sets that only contain a single point. Show that each element of $\sigma \mathcal{C}$ is either countable, or the complement of a countable set.  
	\end{enumerate}
\end{problem}

\begin{solution}
	% (a)
	
	\textbf{1.} The elements of $\sigma \mathcal{C}$ are defined as the intersection of all sigma-algebras that contain $\mathcal{C}$. Since $\mathcal{C}$ contains 3 subsets of $E$, as it is a partition, which implies that $A,B,C$ are disjoint and have a union of $E$. Thus, we can define $\sigma \mathcal{C}$ as the following set:
	\begin{equation}
		\sigma \mathcal{\mathcal} = \{\emptyset, E, \{A\}, \{B\}, \{C\}, \{A\cap B\}, \{A\cap C\}, \{B\cap C\}\big\}
	\end{equation}
	This set contains $E$, all partitions of closures by $E$ generated from $\mathcal{C}$. Thus, this is the smallest sigma-algebra that contains $E$ generated by $\mathcal{C}$.
	
	\textbf{2.} Since $\mathcal{C}$ is a partition,  $\bigcup \mathcal{C} = E$. We need to show that $\sigma \mathcal{C}$ contains only elements from $C$. We can take $\varepsilon$ as the set of all countable unions taken from $E$. We can show that this is a sigma-algebra by taking its definitions. Since $\varepsilon$ contains $E$ the subset of all the partitions, it must also contain the union of none of the partitions, or $\emptyset$. Secondly, by taking all of the unions, we start with the disjoint partitions and then create their unions until we reach $E$. This will be closed under complement as by taking countable unions, we will have the sets that are not part of the union as another subset of a different union. Thus, we can argue that this is the same as $\sigma \mathcal{C}$ by the logic of construction. Thus, since each element of  $\sigma \mathcal{C}$ is isomorphic to the construction that we obtained from the union of subsets, we have shown that all elements are just a set of unions in $\mathcal{C}$.
	
	\textbf{3.} Define the set $\mathcal{A} = \{ A \subset \mathbb{R} : A \text{ is countable or } A^c \text{ is countable}\}$. We want to show that this is a sigma-algebra. Since $\emptyset$ is countable, it is contained within $\mathcal{A}$. $\emptyset \in \mathcal{A}$. The complement of this is the set of reals; $\mathbb{R} = \emptyset^c \in \mathcal{A}$. By definition, if $A$ is countable, then $A^c$ is co-countable. Similarly, if $A$ is co-countable, this implies that $A^c$ is countable. Thus, both sets are contained in $\mathcal{A}$. 
	
	Thus, consider a sequence $(A_n)_{n\in\mathbb{N}} \subset \mathcal{A}$. the union of this sequence is $\bigcup_n A_n$. This is split into cases. First, if all $A_n$ are countable, so it the union, which is included in $A_n$. If all $A_n$ are co-countable, then consider the compliment of the union $(\bigcup_n A_n)^c = \bigcap_n A_n^c$ which is an intersection of countable sets, which is countable. If there is a mix between countable and co-countable sets, they are co-countable, which are contained in $A$ by the previous definition. Thus, $\bigcup_n A_n \in \mathcal{A}$. Thus, $\mathcal{A}$ is closed under union and complement. Thus, $\mathcal{A}$ is a sigma-algebra. Thus, $\sigma \mathcal{C} \subset \mathcal{A}$
	
	We want to show that any countable set is a union of the singletons. Since $A$ contains countable and co-countable sets, $A$ is a union of singletons, which are by definition contained in $\mathcal{A}$.
	\begin{equation}
		A = \bigcup_{x\in A}\{x\}
	\end{equation}
	For co-countable sets in $A$, we note that the complements are countable, which are contained in the above definition. Since $\mathcal{A}$ consists of countable sets, these are the countable unions of singletons contained in $\sigma \mathcal{C}$. Since $\mathcal{A}$ also consists of co-countable sets, these are the complements of intersections of countable sets in $\sigma \mathcal{C}$. Thus, $\mathcal{A} \subset \sigma \mathcal{C}$.
\end{solution}

\begin{problem}
	Let $(E, \varepsilon)$ be a measurable space. Fix $D\subset E$ and let $$\mathcal{D} = \varepsilon \cap D = {A \cap D} : A \in \varepsilon$$ Show that $\mathcal{D}$ is a sigma-algebra on D. It is called the trace of $(E, \varepsilon)$ on $D$.
\end{problem}

\begin{solution}
	To show that $\mathcal{D}$ is a sigma-algebra, we need to show closure under union, complement, intersection, and the existence of $D, \emptyset \in \mathcal{D}$. 
	
	\begin{enumerate}
		\item To show that $D, \emptyset \in \mathcal{D}$ i will write out the logical steps. Since $D\subset E$, $D\in \epsilon$. Since $A = D, D\cap D = D$. By defintion of $\mathcal{D}$, $D \in \mathcal{D}$. Similarily, $\emptyset\subset E$, $\emptyset\in \epsilon$. Since $A = \emptyset, \emptyset\cap D = \emptyset$. By defintion of $\mathcal{D}$, $\emptyset \in \mathcal{D}$.
		
		\item The closure of complement can be shown by the set property of $D^c$. Since $E^c = \emptyset$, $D^c = E\ D$.
		\begin{align*}
			 \left(A_n \cap D\right)^c &= A^c \cup D^c \\
			 &= A^c \cup (E \ D)\\  
			 & = E \ (D\ A) \\
			 &\in \mathcal{D}
		\end{align*}
		Thus $\left(A_n \cap D\right)^c \in \mathcal{D}$.
		
		\item For union and intersection we will use a similar set operation;
		\begin{align*}
			\left(\bigcup_{i=1}^\infty A_i\right) \cap D &=\lim  \left(A_1 \cup A_2 \cup \dots \cup A_n\right) \cap D\\
			&= \lim (A_1\cap D) \cup (A_2\cap D) \cup \dots \cup (A_n\cap D)\\
			&= \bigcup_{i=1}^\infty(A_i\cap D)\\
			& \in \mathcal{D}
		\end{align*}
		
		\begin{align*}
			\left(\bigcap_{i=1}^\infty A_i\right) \cap D &= \left(A_1 \cap A_2 \cap \dots \cap A_n\right) \cap D\\
			&= \lim (A_1\cap D) \cap (A_2\cap D) \cap \dots \cap (A_n\cap D)\\
			&= \bigcap_{i=1}^n(A_i\cap D)\\
			&\rightarrow \left( \bigcap_{i=1}^\infty(A_i\cap D) \right)^c\\
			&= \bigcup_{i=1}^\infty(A_i\cap D)^c \\
			&= \bigcup_{i=1}^\infty(A_i^c\cup D^c) \\
			\text{By the closure of the complement: }& \in \mathcal{D}
		\end{align*}
	\end{enumerate}
	Thus we have shown that $\mathcal{D}$ is a sigma-algebra on $D$.
\end{solution}

\section{Measurable Functions}

Functions from a set $E$ to $F$ is a rule that assigns an element $f(x)$ of $F$ to each $x$ in $E$; $f:E\rightarrow F$. Given a subset $B$ of $F$, the inverse image of $B$ under $f$:
\begin{equation}
	f^{-1}B = \{x\in E: f(x) \in B\}\,.
\end{equation}
The properties of these functions are as follows;
\begin{definition}
	Properties of the set function;
	\begin{enumerate}
		\item $f^{-1}\emptyset = \emptyset$.
		\item $f^{-1}F = E$.
		\item $f^{-1}B\setminus C = (f^{-1}B)\setminus (f^{-1}C)$.
		\item $f^{-1}\bigcup_i B_i = \bigcup_i f^{-1} B_i$
		\item $f^{-1}\bigcap_i B_i = \bigcap_i f^{-1} B_i$
	\end{enumerate}
	\begin{proof}
		\begin{enumerate}
			\item Since $\emptyset$ has no elements, there is no $f(x)$ in $\emptyset$. Thus, there is no such $x$ that satisfies this.
			\item Since $f$ is a map from $E \rightarrow F$, each value of $F$ has an inverse mapping to some element in $E$. This mapping need not be bijective, however, it is surjective. Thus, The inverse set of $F$ must be $E$ by construction.
			\item Let $x \in f^{-1}B\setminus C$. Then, $f(x) = B\setminus C$. Here $f(x) \in B$, and $f(x) \notin C$. So define the inverse image, $f^{-1}B = \{x\in E:f(x) \in B\}$, and $f^{-1}C = \{x\in E:f(x) \in C\}$. It is apparent that $x \in f^{-1}B$. Similarly, $x\notin f^{-1}C$ as $B\setminus C \notin C$. Thus, $x\in f^{-1}B$ and $x\notin f^{-1}B$. So $f^{-1}B\setminus C = f^{-1}B\setminus f^{-1}C$.
			\item For all $f(x) = \cup_i B_i$ there exists a pre-image $y = f^{-1}(\cup_i B_i)$. Thus, there exists an $i$ such that $y \in B_i$. This implies that if there is at least 1 $i$ that conditions this, then there is at least 1 pre-image $y = f^{-1}B_i$. Then, to ensure all values on $E$ are contained, $y = \bigcup_i f^{-1}B_i$. Hence, $f^{-1}\bigcup_iB_i=\bigcup_i f^{-1}B_i$.
			\item Since for all $f(x) = \cap_i B_i$ then $f(x) \in B_i$ for all $i$. This implies that the pre-image, $y$ such that $y = f^{-1}(\cap_i B_i)$ is contained within all each and every $f(x)$ simultaneously. That is $y = \cap_i f^{-1}(B_i)$. Thus  $f^{-1}(\cap_i B_i)= \cap_i f^{-1}(B_i)$.
		\end{enumerate}
	\end{proof}
\end{definition}

Measurable functions are defined as maps between measurable spaces. Let $(E, \mathcal{E})$ and $(F, \mathcal{F})$ be measurable spaces. A measurable function is defined as 
\begin{equation}
	f : E \rightarrow F, \quad f^{-1}B \in \mathcal{E} \quad \forall B \in \mathcal{F}
\end{equation}
In english, this is stating that for some function $f$ from $E$ to $F$ there exists a pre-image $f^{-1}$ that maps from some element $B$ in $\mathcal{F}$ to some element in $\mathcal{E}$. Or that there is a pre-image map between the subsets in the sigma-algebras of each of the spaces. 

In order for $f:E\rightarrow F$ to be measurable, it is necessary that for some collection $\mathcal{F}_0$ that generates $\mathcal{F}$, meaning that the intersection of all sigma-algebras containing $\mathcal{F}_0$ is equal to $\mathcal{F}$, we have that $f^{-1}B \in \mathcal{E}$ for all $B \in \mathcal{F}_0$.

In english, if one wants to test that a function is measurable, it is only necessary to test on a subset that generates it.

\begin{proof}\label{prop:2p3}
	Why is this necessary? Suppose that there is no such $\mathcal{F}_0$. If the sigma-algebra then does not exist then $\mathcal{F}$ is not the smallest sigma-algebra that exists on $E$. This fact implies that $F$ is not a measurable space. 

	Sufficiency of this claim is now proved. Let $\mathcal{F}$ be the smallest sigma-algebra generated by $\mathcal{F}_0$. Then, we need to show that the inverse of $E$ is contained within $\mathcal{F}$. Here, 
	\begin{equation}
		\mathcal{F}_1 = \{B\in \mathcal{F}: f^{-1}B \in \mathcal{E}\}\,.
	\end{equation}
	Thus, we need to show that $\mathcal{F}_1$ is a sigma-algebra. By the properties of functions, this map is obviously closed under union and since it contains the sample space, it is also closed under complement via the property of set subtraction. 
\end{proof}

The composition of functions is defined by 
\begin{equation}
	g\circ f (x) = g(f(x)), \quad x \in  E\,,
\end{equation}
for a mapping $f: E\rightarrow F$ and a mapping $g: F\rightarrow G$
. The inverse composition is defined by
\begin{equation}
	(g\circ f)^{-1} (x) = f^{-1}(g^{-1}(x)), \quad x \in  G\,.
\end{equation}
We can prove that measurable functions of measurable functions are measurable. Let $f$ be a measurable function on $E$ from $\mathcal{E} \rightarrow \mathcal{F}$. Let $g$ be a measurable function on $F$ from $\mathcal{F} \rightarrow \mathcal{G}$. Then, $(g\circ f)$ is measurable from $\mathcal{E} \rightarrow \mathcal{G}$;
\begin{proof}
	The inverse, $(g\circ f)^{-1}$, can be expanded and acted on some $C\in \mathcal{G}$;
	\begin{align*}
		(g\circ f)^{-1}C &= f^{-1}(g^{-1}C)\,,\\
		&= f^{-1}(B), \quad \mathrm{where} B \in \mathcal{F}\,,\\
		&= A, \quad \quad \mathrm{    where }A \in \mathcal{E}\,.
	\end{align*}
	Thus, $g\circ f$ is measurable.
\end{proof}

\subsection{Numerical Functions}

A numerical function in measure theory is a function whose codomain is a set of numbers (such as real numbers \(\mathbb{R}\), extended real numbers \(\overline{\mathbb{R}}\), or complex numbers \(\mathbb{C}\)), rather than general abstract spaces. Before diving into the weeds, define notation for the real numbers;
\begin{align*}
	\mathbb{R} &= (-\infty, \infty)\,,\\
	\bar{\mathbb{R}} &= [-\infty, \infty]\,,\\
	\mathbb{R}_+ &= [0, \infty)\,,\\
	\bar{\mathbb{R}}_+ &= [0, \infty]\,,\\
\end{align*}
where $\bar{\cdot}$ represents the extended number system, which adds absolute minima and maxima to the set of real numbers. Define the Borel sigma-algebra as $\mathcal{B}(\bar{\mathbb{R}})$, which is the smallest sigma-algebra on the set of real-numbers.

\begin{definition}
	The mapping $f:E\rightarrow \bar{\mathbb{R}}$ is $\mathcal{E}$-measurable if and only if for every $r$ in $\mathbb{R}, f^{-1}[-\infty, r] \in \mathcal{E}$.
	\begin{proof}
		This is just an application of Prop. \ref{prop:2p3}. Let $B$ be an element of a subset $\mathcal{F}_0$ of the real numbers. Then, for $f$ to be measurable wrt $\mathcal{E}$, for each $B$, $f^{-1}B\in \mathbb{R}$.
	\end{proof}
\end{definition}

\subsection{Positive and negative parts of a function.}

A function $f$ can be decomposed into negative and positive parts. Let the notation $a \wedge b$ and $a\vee b$ denote the minimum and maximum between $a$ and $b$ respectfully. 

Let $f$ be a numerical function on $E$. Then,
\begin{equation}
	f^+ = f \vee 0, \quad f^- = -(f \wedge 0),
\end{equation}
denote the positive and negative parts of the functions. 
\begin{definition}
	The function $f$ is $\mathcal{E}$-measurable, meaning that is is a map $f:E\rightarrow \mathbb{R}$ and is measurable from $\mathcal{E}$ to $\mathcal{B}(\mathbb{R})$ if and only if both $f^+$ and $f^-$ are. 
	\begin{proof}
		The decomposition of $f$ is shown below;
		\begin{equation}
			f = f^+ - f^-,
		\end{equation}
		where, 
		\begin{eqnarray}
			f^+ = f \vee 0, \quad f^- = -(f\wedge 0)
		\end{eqnarray}
		To prove this, we need to show that the decomposition is measurable using Prop 2.3 in Cinlar. 

		For a pair $(E, \mathcal{E})$, the domain of both of these functions are elements of $E$, or some subset in $\mathcal{E}$. From this, it is obvious that when one of the functions has a non-zero image, the other part will be zero. It should be noted that the quantities $f^+$ and $f^-$ are both greater than or zero to 0. 

		Now, the proof relies on checking for measurability. Let $\mathcal{E}_0$ be the subset of $\mathcal{E}$ which returns a non-zero value in $f^+$. This collection of subsets, $\mathcal{E}_0 \subset \mathcal{E}$. This set is a generator of $\sigma\mathcal{E}$. Thus, it is necessary to show measurability on this subset. 

		By construction of a numerical function, every element in $\mathcal{E}$ is measurable with respect to $\mathcal{B}(\mathbb{R})$.

		In other words, if $f$ is measurable, the functions $f^+, f^-$ are measurable as the transformations
		\begin{equation}
			f^+ = \frac{|f|+f}{2}, f^- = \frac{|f|-f}{2},
		\end{equation}
		are continuous, which implies that $f^+, f^-$ are measurable if $f$ is measurable. The converse is an application of the composition of measurable functions. 
	\end{proof}
\end{definition}

\subsection{Limits of sequences of functions}
Let $(f_n)$ be a sequence of numerical functions on $E$. The functions 
\begin{equation}\label{thm:215_stuff}
	\inf f_n, \quad \sup f_n, \quad \lim \inf f_n, \quad \lim \sup f_n
\end{equation}
are defined on $E$ point-wise. In general, if the function at $x$ has a limit inferior equal to the limit superior, then the function is said to have a point-wise limit $f$ and we write 
\begin{equation}
	f = \lim f_n\,.
\end{equation}
\begin{definition}
	Let $(f_n)$ be a sequence of $\mathcal{E}$-measurable functions. Then, each of the functions in Eqn. \ref{thm:215_stuff} is $\mathcal{E}$-measurable. Moreover, if it exists, $\lim f_n$ is $\mathcal{E}$-measurable.
\end{definition}

Some examples of measures are listed below for the measurable space $(E, \mathcal{E})$;

		1 & x \in A \\ 0 & x\notin A 
	\end{cases}\]
	\item Counting Measure: Let D be a fixed subset of $E$. The counting measure counts the number of points $A\cap D$. We interpret this as all elements outside D have zero measure and all elements of D have equal measure. \[ \#_D(A) = \sum_{x\in D} \delta_x(A),\quad A \in \mathcal{E}\]
	\item Discrete Measure: Let $D$ be a countable subset of $E$, and $m(x)$ a positive number.  \[\mu(A) = \sum_{x\in D} m(x) \delta_x(A), \quad A\in \mathcal{E}\]

\section{Integration}
Let $(E, \mathcal{E}, \mu)$ be a measure space. Here we define $\mathcal{E}$ as the sigma algebra of all $\mathcal{E}$-measurable functions, which are all measurable functions mapping to the Borel sigma-algebra. 

We define the 'integral of $f$ with respect to $\mu$' as:
\begin{equation}
	\mu f = \mu(f) = \int_E\mu(dx)f(x) = \int_E fd\mu
\end{equation}

\begin{definition}
	\begin{itemize}
	\item Let $f$ be simple and positive, such that it has the form $f = \sum_{i =1}^{n} a_i 1_{A_i}(x)$. Then we define \[\mu f = \int  \sum_{i =1}^{n} a_i 1_{A_i}(x) d\mu =  \sum_{i= 1}^{n} a_i \mu(A_i)\]
	\item Let $f$ be in the set of positive $\mathcal{E}$-measurable functions, denoted $\mathcal{E}^+$. Put $f_n = f(d_n(r))$ where $d_n(r)$ is the dyadic function approximating a numerical function. Then, each $f_n$ is simple and positive, and the sequence $(f_n)$ increases to $f$ as per Thm. \ref{thm:217}. The integral $\mu f_n$ for each $n$ is defined by item (a). Define the limit as \begin{equation}
		\mu f= \lim \mu f_n
	\end{equation}
	\item Let $f \in \mathcal{E}$. The functions $f^+, f^-$ belong to $\mathcal{E}^+$ and the integrals $\mu(f^{+/-})$ are defined as per (b). Noting the functional decomposition, if at least one integral of these functions is finite, it exists. Otherwise, if $\mu(f^+) = \mu(f^-) = \infty$ then $\mu f$ is undefined.
	\end{itemize}
\end{definition}

This definition can be used on different measures to see how the integral is defined. 
\begin{enumerate}
	\item Dirac Measure: \[\mu f = \delta_x(A) f(x) = f(A)\]
	\item Discrete Measure: \[\mu f = \sum_{x\in D} m(x)f(x)\]
	\item Lebesgue Integrals:\[\mu f = \text{Leb}_E f = \int_E \text{Leb}_E(dx) f(x) = \int_E dx f(x)\] Note that if the lebesgue exists, so does the riemann integral, which is reminded by the notation in the last equality. Note that the converse is false. 
\end{enumerate}

The main idea of the integral with respect to a measure is packaged in how the measure acts on infinitesimal pieces $dx$. Since the measure gives different weights to different parts of the set. We can use a result that approximates a measurable function $f$ as a convergent sequence of simple functions. That is, we can approximate $f$ using simple functions that partition the domain in a way that converges to the value of the integral.

\subsection{Radon-Nikodym Theorem}
Given a measurable space \((X, \mathcal{X})\), suppose $\mu$ and $\nu$ are $\sigma$-finite measures. If $\nu$ is absolutely continuous with respect to $\mu$ (written as \(\nu \ll \mu\)), meaning \(\mu(E) = 0 \implies \nu(E) = 0\) for all measurable sets E, then there exists a measurable function \(f: X \to [0, \infty)\) such that:

\begin{equation}
	\nu (E)=\int _{E}f\,d\mu \quad \text{for\ all\ }E\in \mathcal{X}
\end{equation}
